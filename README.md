# Pathway

A hands-on project for learning how data is collected, organized, cleaned, transformed, and prepared for analysis and machine learning.

The goal of this project is to understand the data pipeline before focusing on the model itself.

## What I'm Learning

- Data collection
- Data organization
- File and folder structures
- Raw vs processed data
- Data cleaning
- Handling missing values
- Data transformation
- Data validation
- Data preprocessing
- Feature preparation
- Reproducible data pipelines
